# 网易登录验证码

macOS 邮箱登录遇到网易返回 `444`、`445` 或 `447` 时，会弹出“网易人机验证”窗口，加载官方易盾组件。点击“开始验证”或按组件提示操作，通过后工具会自动继续登录。窗口支持重新加载和取消；关闭窗口也会取消本次登录。

只需要在原登录页输入账号和密码。验证码窗口只接收网易提供的验证码标识，密码和开发者平台会话不会传入网页。窗口使用非持久化的 WebKit 数据存储，关闭后释放页面；不会读取用户浏览器的登录资料。验证码提交结果仍须通过网易 URS 的二次校验，不能仅凭网页回调视为登录成功。

## 登录流程

1. 读取网易 `ini` 返回的动态 `capId` 和验证类型；初始化即要求验证时，先完成验证，再提交密码。
2. 在官方易盾组件中由用户完成操作，取得一次性 `validate`。
3. 保留原 HTTP 客户端和 URS Cookie，按类型调用 `vftcp`、`vfccp` 或 `vfscp`。
4. URS 确认后重新获取工作量证明与登录票据，再继续邮箱登录和开发者平台确认。
5. 完成全部登录步骤后才保存共享会话；此后桌面端和无头命令行均可使用。

验证标识变化时使用服务端新值；连续挑战最多提示三次。取消或失败不会保存一个未经确认的新会话。自动刷新和无头登录不弹出验证码窗口，遇到挑战会提示先在桌面端完成验证。

## 支持范围

当前原生窗口覆盖 **macOS** 的易盾滑块、点选和智能验证（`444 / 445 / 447`）。传统图片验证码（`441`）、短信及账号管家验证不在此窗口中实现。其他系统遇到易盾验证会明确提示当前没有原生验证窗口；普通邮箱和海外账号登录流程保留。

验证码必须由用户完成。自动测试使用合成响应验证会话、取消和重试流程，不调用真实账号，也不将模拟结果记为真人验证成功。


## 接口依据

实现依据为 2026-10-19 读取的[网易官方 URS 登录组件](https://dl.reg.163.com/webzj/v1.0.1/pub/index_dl2_new.html)及其加载的[官方脚本](https://urswebzj.nosdn.127.net/webzj_cdn101/pp_index_dl_4ffdd3b9e3219bd5e76dac9200b67e79.js)。其中 `447` 映射到验证类型 `6`，智能验证取得结果后调用 `vfscp`，通过后重新触发登录。SDK 入口为 [易盾官方加载器](https://cstaticdun.126.net/load.min.js)，URS 使用专用的 `webzjcaptcha.reg.163.com` 与 `webzjac.reg.163.com` 服务。

独立的验证码页面允许官方 SDK 编译其模板所需的脚本能力，限制网络脚本和连接到网易相关域名，并禁止表单提交与任意顶层跳转。原生结果桥接校验主框架、每次随机值及结果长度；不提供通用浏览器入口。
